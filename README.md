# Flawless Skin Care

Full-stack website for Flawless Skin Care, a skincare and beauty business in Limbe, Cameroon.

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS + shadcn/ui
- Supabase (PostgreSQL, Auth, Storage)
- Vercel (hosting)

## Getting started

1. Copy `.env.example` to `.env.local` and fill in the values
2. `npm install`
3. `npm run dev`
4. Open http://localhost:3000
